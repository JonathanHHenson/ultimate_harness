# Learn a Topic

## Frame the question

- Identify what the user wants to understand or what decision depends on the answer. Define the relevant context, constraints, and what would count as sufficient evidence. For a project decision, start with governing requirements, current documentation, and observed behavior.
- State a provisional explanation or approach, its key assumption, and what evidence would change it. Choose the next question most likely to resolve uncertainty. Scale depth to the stakes and ambiguity.

## Investigate and challenge the explanation

- Use [research and Socratic inquiry](references/research.md) to assess accuracy, relevance, and trustworthiness. Prefer direct evidence such as primary research, authoritative documentation for the applicable version, or a reproducible observation. Keep the smallest set that supports the material claims and represents credible dissent.
- Compare viable explanations or approaches under the same conditions. Seek a strong counterexample or opposing view. If sources disagree, check whether they address the same question, assess how the evidence was obtained, and look for a discriminating observation. When progress stalls, consult a worked example, a more direct source, or relevant expert feedback.
- Test the explanation when feasible. Predict an observable result on a representative or fresh case before checking it. Use a different input, version, setting, or prerequisite when it tests an assumption. Update the conclusion when the evidence contradicts it and state what remains uncertain.

## Return the findings

- Record the consequential claim, source or check, what it establishes, where it applies, and what remains unresolved. Keep working notes in the agent session's scratch workspace when available. A low-stakes question may only need a brief record.
- Present the conclusion with the strongest evidence, the tradeoff or counterexample that matters, and any limitation that could change the answer. When another workflow requested the research, give it the findings and applicable conditions. Stop once further inquiry is unlikely to change the decision or the remaining evidence is unavailable.
