# Project Language Skills

## Before working with a language used in the project

- Load each skill that applies to the change. For mixed files, apply the tooling for their executable and rendered parts.

| Work | Skill |
| --- | --- |
| Python source, tools and tests | [Python development](../../.agents/skills/python-development/SKILL.md) |
| Browser JavaScript and Node tools | [JavaScript development](../../.agents/skills/javascript-development/SKILL.md) |
| HTML templates and rendered markup | [HTML development](../../.agents/skills/html-development/SKILL.md) |
| CSS layout and styles | [CSS development](../../.agents/skills/css-development/SKILL.md) |
| Shell scripts and workflow script blocks | [Shell development](../../.agents/skills/shell-development/SKILL.md) |

## When onboarding another project language

- Use [the language skill workflow](../../.agents/skills/learn-and-build-skills/SKILL.md#when-authoring-a-language-skill). Add the resulting skill to this routing table and add its reusable files to the export catalog.
