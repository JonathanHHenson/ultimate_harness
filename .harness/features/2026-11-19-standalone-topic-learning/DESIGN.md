# Standalone topic learning

## General method (LEARN-1)

Install a standalone project skill called learn-a-topic. Move the current research reference under that skill and revise its scope so inquiry, source assessment, evidence reconciliation, and transfer apply to any topic. Keep the standalone entry point focused on the question, evidence, decision, and limits. Keep research notes in the current scratch workspace when one exists.

## Callers and lifecycle (LEARN-2)

Preserve the existing learn-and-build-skills name and skill-specific workflow. Resolve its research step through a relative link to the sibling skill. Load that same skill from build-harness when consequential premises need checking, and from the validation authoring reference when adding or materially changing a rule. Keep a new validation rule's acceptance criteria in the existing validation authoring workflow. Delete the superseded reference after both callers are in place.

## Verification (LEARN-3)

Validate all three packages and local Markdown links. Check that a direct topic request ends with evidence and limits, skill authoring uses the learning handoff before packaging, and a routine harness edit does not start a research pass. Independently use the staged harness route to research an example validation rule, run small checks, and write a rule in scratch. No project rule is required for the example itself.
